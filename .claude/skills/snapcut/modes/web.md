# 웹사이트 애니메이션 모드 (web)

렌더 후 마스터링·점검과 완성 보고는 SKILL.md §3을 따른다. 결과는 두 개: 빌드된 사이트 `projects/<이름>/output/site/`와 미리보기 `projects/<이름>/output/<이름>_web.mp4`. 아래 `P` = `projects/<이름>`. **`.venv/bin/python -m pipeline …`은 저장소 루트에서, npm은 `P/work/web`에서 실행한다.**

1. **키트 읽기** — `kits/motion-dev-animations-skill/SKILL.md`(흐름·결정표·성능 규칙)와 `examples/*.md`(hero-fade-up, scroll-reveal, parallax-layers, card-hover, magnetic-button), `templates/`(Tailwind 클래스를 쓰니 그대로 붙이지 말고 CSS로). SKILL.md가 가리키는 문서 중 저장소에 없는 것(Performance, Accessibility 등)은 건너뛴다.
2. **프로젝트** — `mkdir -p P/work P/output` 뒤 `P/work`에서 `npx -y create-vite@9.2.1 web --template react --no-interactive` → `P/work/web`에서 `npm i --no-audit --no-fund` → `npm i --no-audit --no-fund motion`. `vite.config.js`의 `plugins` 다음에 `base: './',`와 `build: { outDir: '../../output/site', emptyOutDir: true },`. `index.html`은 `lang="ko"`·제목.
3. **페이지** — `src/App.jsx`에 키트 패턴: 등장 0.6–0.8초 `ease [0.22, 1, 0.36, 1]`, 0.1–0.15초 간격, 스크롤 `whileInView`(`viewport {once: true, amount: 0.3}`)·`useScroll`+`useTransform`, 호버 스프링 400/20(**`whileHover={{y: -8, transition: {type: 'spring', stiffness: 400, damping: 20}}}` 안에** — 요소의 `transition` prop에 두면 등장 애니메이션의 시간·간격을 덮어써 카드가 한꺼번에 뜬다), transform·opacity만, `useReducedMotion()`. 외부 글꼴·이미지 요청 없음(한글은 `"Apple SD Gothic Neo", system-ui, sans-serif`).
4. **미리보기용 seek 경로** — 실제 사이트는 시계로 움직이므로 `?render`일 때만: 실시간 애니메이션(initial/whileInView/스프링)을 끄고, 마운트 후 `const seq = animate([[선택자, {opacity: [0, 1], y: [40, 0]}, {duration, ease, delay: (i) => i * 0.12, at: 초}], …]); seq.pause();` 하나로 묶은 뒤 `window.seek = (t) => { seq.time = …; scrollTo(0, 스크롤 키를 smoothstep으로) }`, `document.fonts.ready.then(() => { window.__ready = true; })`. 호버는 시퀀스 안에서 흉내(버튼 y -6). 스크롤 키는 섹션의 `getBoundingClientRect().top + scrollY`로 잡고, 끝에 1초 넘게 멈춘 화면이 길면 작은 움직임을 남긴다.
5. **빌드** — `P/work/web`에서 `npm run build` → `P/output/site/`. 키트 규칙의 번들 50KB는 React + Motion으로는 넘는다(예시 117KB gzip) — 넘으면 그렇다고 말한다.
6. **미리보기** — `.venv/bin/python -m pipeline capture P/output/site P/output/<이름>_web.mp4 --seconds 14 --size 1920x1080`(폴더를 주면 로컬 HTTP로 띄워 찍는다 — 빌드된 모듈 스크립트는 `file://`로 안 돈다) → `.venv/bin/python -m pipeline master P/output/<이름>_web.mp4` → `.venv/bin/python -m pipeline check <이름> P/output/<이름>_web.mp4`. 소리가 없어 음량은 건너뛴다. 사용자에게는 사이트 폴더(`npx serve P/output/site` 등으로 열기)와 미리보기 경로를 함께 준다.
