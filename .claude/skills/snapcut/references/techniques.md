# 카메라 워크·장면 전환 — 느낌을 기법으로

사용자가 느낌으로 요청하면("몽환적으로", "긴장감 있게", "후렴에서 확 터지게") 이 파일로 기법을 고른다. 모든 모드 공통.

## 제안하는 방법
1. 느낌 → 아래 §2 연결표에서 기법 1~3개를 고른다. 영상 전체가 아니라 **어느 구간(곡 시각·장면)** 에 쓸지 정한다.
2. 각 기법을 **기법 · 지속 시간 · 속도 · 피사체 · 방향** 한 줄로 쓰고, 바로 아래에 실제로 넣을 값을 붙인다.
   - 예) `크로스 디졸브 · 1초 · 일정하게 · 노을 영상 → 단체 사진 · —` → 단체 사진 항목에 `"dissolve": 1.0`
3. §1 표의 상태가 "촬영"이면 **"이미 찍은 영상에서는 만들 수 없음"이라고 말하고** 원본에서 그런 움직임이 있는 컷을 찾거나 지금 되는 가장 가까운 기법을 제안한다. 비슷하게 흉내 내고 됐다고 하지 않는다. 전환(dissolve·blur·whip·wipe)은 항목당 하나다.
4. **취향 기록이 이 표보다 우선한다.** 추억 뮤비 사진에는 줌·팬을 넣지 않는다(이동·확대가 어지럽다는 반응. 풍경 하이라이트 몇 장의 zoom-in만 예외). "역동적으로"라도 사진 움직임 대신 컷 속도·영상 선택으로 푼다.
5. 한 영상에 기법을 다 쓰지 않는다. 구간마다 하나의 문법을 정해 반복하는 게 더 세련돼 보인다.

## 2. 느낌 → 기법

| 사용자가 말하는 느낌 | 먼저 쓸 기법 | 함께 조절할 것 |
|---|---|---|
| 몽환적, 꿈같이, 회상 | 크로스 디졸브(0.6~1초), 랙 포커스(블러 전환), 슬로 모션 | 컷 길게(사진 2.5초+), 잔잔한 구간 |
| 잔잔하게, 따뜻하게 | 크로스 디졸브, 정지 사진, L컷 | 현장 소리 줄이기, 느린 박에 맞춤 |
| 신나게, 빠르게, 경쾌하게 | 점프 컷, 휩 팬, 스피드 램프 | 컷을 비트·반 마디에, 영상 1.5~2초 |
| 확 터지게, 반전, 빵 터지게 | 스매시 컷 | 직전 구간을 조용히, 터지는 박에 `{"at"}` 마커, 현장 소리 크게(`"duck"`) |
| 웃기게, 코믹 | 프리즈 프레임, 스매시 컷, 점프 컷 | 웃음 순간을 프레임 시트로 찾아 `in` |
| 긴장감, 불안 | 더치 앵글, 핸드헬드, 스매시 컷 | 짧은 컷 연속 후 정적 |
| 웅장하게, 장대하게 | 크레인 업·오빗·FPV 원본 컷, 틸트 | 후렴 첫 박에 배치, 길게 |
| 현장감, 생생하게 | 핸드헬드 원본 살리기, 트래킹 컷, J컷 | 최상위 `"liveAudio": true` |
| 여운 있게 끝내기 | L컷, 느린 디졸브, 크레인 업 컷 | 마지막 `"fadeOut"` 또는 `"outroDissolve"` |
| 시간이 흐르는 느낌, 하루 요약 | 타임랩스, 점프 컷, 크로스 디졸브 | 시간순 유지 |
| 인물 소개, 주인공 강조 | 프리즈 프레임, 줌 인(사진 한 장), 오빗 컷 | 화면에 시선 갈 곳 하나 |
| 다음이 기대되게 | J컷, 휩 팬 | 구간 끝 직전 |
| 임팩트 있게, 후렴에서 터지게 (효과음·플래시까지) | 스매시 컷 + `effects.sfx`·`effects.beatAccent` | 드롭은 마지막 후렴 첫 박 — 그 전 구간은 잔잔하게 |
| 옛날 필름 같은, 아날로그 감성 | `effects.filmLook` + 크로스 디졸브 | 채도 높은 사진은 줄이고 노을·풍경 위주 |
| 포스터·잡지 표지 같은 제목 | 사진 항목 `behindTitle` (글자가 사람 뒤로) | 하늘이 위에 있는 가로 인물 사진 |
